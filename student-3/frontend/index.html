AI Product Consultant

Conversational, catalog-grounded product advice for OmniTech Marketplace.

Launch the service

The consultant is a Flask microservice. When the shared Docker Compose stack is running it is served on port 5003.

Open chat Open dashboard

What it does

  • HTMX chat interface for describing tech requirements
  • Dashboard of past consultations and saved recommendations
  • Agentic loop: catalog context, Ollama prompt, output validation, corrective re-prompt
  • REST API owning the ConsultationSessions, ChatLogs and SavedRecommendations tables
